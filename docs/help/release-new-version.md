# How to release a new version of your game or roll back

Drop the new ZIP on the game card in the studio, play the new version, confirm whether it is a fix, a new feature or a new look, and release it. The previous version stays with us, one button away.

## Before you start

- The game is already published from the studio at dev.klyo.pl.
- The new build as a ZIP with index.html inside. The address, scores, reviews and statistics stay the same.
- Or an AI assistant connected over MCP, which can patch the files in a draft for you to release.

## Step by step

1. **Upload the new build**: Open the studio, find the game and drop the new ZIP on its card, or press **New build** on the card and choose the file. The studio checks it with the same rules as the first upload. Players still get the old version at this point.
2. **Play the new version**: Press **Play the new version** and check that it starts and reacts, best on your phone. If something is off, press **Upload a different package**.
3. **Say what changed**: The studio compares the files with the live version and suggests the answer: a fix keeps the current clip, a new feature asks for a new clip that goes to the feed as New, and a new look takes the old clip off the tile until you record another. Add one sentence about what is new if you like.
4. **Release**: Press **Release**. Players get the new version right away: whoever is in the middle of a round chooses to update or to finish it first. People who follow you get a notification about the new version.
5. **Go back if you need to**: Something slipped through? On the game card press **Back to the previous version** and confirm. Players are offered a refresh and get the previous build.

## If something goes wrong

### The new build is refused

The check names the reason, exactly as at the first upload. Fix it and upload again; the live version is not touched.

### The clip no longer matches the game

After a new look the old clip leaves the tile and the feed. Record a new one from the game card with **Play and record a clip**.

### The new version shows a white screen

Go back with **Back to the previous version**, then press **Show what happened** in the preview of the new build to see the missing files and errors.

## Common questions

### Does a new version change the address or the scores?

No. The address, scores, records, reviews and statistics stay. Only the files of the game change, and the previous version stays available for a rollback.

### Can an AI assistant release a new version?

Yes. Over the klyo MCP server it uploads the new build or patches files in a draft, and releases it when you say so. Playing the new version first stays your check.
