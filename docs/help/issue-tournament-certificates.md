# How to issue certificates to tournament players

After the tournament, open its page, press “Certificates”, choose the language, type the names and press “Download PDF”. Every certificate gets its own Klyo code, and each player also receives their code by email.

- 2 min read
- Steps: 5

### On this page

## Before you start

- A finished tournament in which you are the organiser, the accepted referee, or a captain or coach of the club that ran it.
- A player without these roles downloads only their own certificate, with the “Your certificate” button on the tournament page.
- The first and last names of students or players, if they should replace nicknames. Klyo remembers them on this device for the next print.

## Step by step

1. **Open the finished tournament**: Go to the tournament page. Under the champion there is a **Certificates** button. Before the end, the page shows a sample certificate so players know what they will get.
2. **Choose the language and players**: Choose the certificate language: Polish, English, German or Ukrainian. Tick players on the list or press **Podium**. The podium always shows the place, the others get a certificate for taking part unless you put the place on every certificate.
3. **Type names, organiser and referee**: Click a player on the list and type a first and last name under the preview if it should replace the nickname. Fill in the organiser and the referee. The preview shows the certificate exactly as it will print.
4. **Download a PDF or print**: Press **Download PDF**. The file is built in your browser, one A4 page per certificate, without waiting for the server. You can also press **Print**. The server counts the places from the matches, and each player receives the code of their certificate by email.
5. **Hand out the certificates**: You can send the PDF to parents or print it on landscape A4 paper. The QR code works on paper and on a screen. A school can hand out the certificates at an assembly, and anyone who receives one can check it with a phone on the tournament page, without an account and without installing anything.

## If something goes wrong

### I do not see the certificates button

The organiser, the accepted referee and the club staff see it. A player sees “Your certificate”. The tournament has to be finished.

### I want to fix a name on an issued certificate

Issue the certificate again with the corrected name. The code stays the same, and the check page shows the new details and the new date.

### A player did not get the email with the code

The email goes to the confirmed address of the player account. If the account has no confirmed address, the player sees their certificate on the tournament page with the “Your certificate” button.

### The PDF takes a while

The file is built in your browser in print quality, so it does not wait for the server. With dozens of certificates it takes a few seconds, and the counter on the button shows the progress.

### A player wants the certificate in another language

The player downloads their own certificate with the “Your certificate” button and chooses one of the four languages. The code stays the same, so the check shows the same record.
